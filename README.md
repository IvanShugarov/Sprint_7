# 🛴 Автоматизация тестирования REST API сервиса «Яндекс.Самокат»

Проект представляет собой фреймворк для автоматизации бэкенд-тестирования ключевых ручек и бизнес-логики сервиса заказа самокатов «Яндекс.Самокат».

## 🛠️ Стек технологий
* **Язык и движок**: Python, Pytest
* **Сетевой клиент**: Requests
* **Архитектура**: Разделение на независимые API-классы, изолированные фикстуры предусловий

## 🔍 Что покрыто API автотестами
1. **Создание курьера**: Позитивные сценарии регистрации, негативные тест-кейсы на обязательность полей (логин, пароль) и проверку обработки дубликатов в базе данных.
2. **Авторизация курьера**: Успешный вход в систему, получение токена, обработка ошибок при вводе неверного логина или пароля.
3. **Управление заказами**: Создание нового заказа с параметризацией различных цветов самоката, а также проверка ручки получения списка всех существующих заказов.

## 🚀 Как запустить тесты локально
```bash
pip install -r requirements.txt
pytest tests/
```
